# Воду в сток

Демонстрация сайта для клиента: https://kolokolchi.github.io/vodu-v-stok-site/

Каталог, 3D-калькулятор, сохранение расчёта и истории, PDF/CSV, подбор через WhatsApp.

Обновление от 13 ноября 2026: отдельные изображения для 34 товаров, новые визуализации систем и категорий, адаптивные изображения, исправленные размеры профилей и материалы в 3D, восстановление модели после сбоя WebGL без перезагрузки страницы.

Перед публикацией пройдены 87 автоматических тестов, проверки пяти размеров экрана и 30 сочетаний параметров 3D-модели. В сборке 51 маршрут.

Этот репозиторий содержит только готовую сборку. Исходный код хранится отдельно. GitHub Pages публикует ветку main из корня репозитория. Демо помечено noindex, nofollow.
