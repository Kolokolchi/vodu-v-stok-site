# Воду в сток

Демонстрация сайта для клиента: https://kolokolchi.github.io/vodu-v-stok-site/

Каталог, 3D-калькулятор, сохранение расчёта и истории, PDF/CSV, подбор через WhatsApp.

В обновлении от 19 ноября 2026 года план дома можно нарисовать по точкам или собрать из прямоугольников и треугольников. Каждую фигуру можно перемещать, поворачивать и менять в размерах. По общему контуру строится 3D-дом и рассчитывается водосток. Стоимость комплекта отображается в тенге.

Гид по выбору: https://kolokolchi.github.io/vodu-v-stok-site/guide/ . Обновление от 14 ноября 2026: сравнение ПВХ и стали по шести характеристикам, пять переключаемых условий эксплуатации, пояснения о других материалах, замеры и воронки, список перед заказом и ответы на вопросы. На главной добавлены прямые ссылки на разделы существующего гида. Рекомендации сопровождаются источниками производителей; новая страница не создавалась.

Для обновления гида пройдены 88 существующих тестов, TypeScript и статическая сборка. В браузере проверены переключатели, управление с клавиатуры, раскрывающиеся ответы, фотографии, переход с главной к нужной части гида и ширины 320, 390, 768, 1440 и 2020 px. Горизонтального переполнения и ошибок JavaScript в этих сценариях нет.

Обновление от 14 ноября 2026: выбор цвета меняет изображение в каталоге и карточке товара, включая вкладку размеров. Для всех 28 товаров с выбором цвета подключены 84 заводских варианта: графит, коричневый и белый. Оцинкованный удлинитель и пять позиций безопасности кровли сохраняют собственные изображения. Учтён полный каталог из 34 товаров.

Перед публикацией пройдены 88 автоматических тестов, TypeScript, ESLint и обе производственные сборки. В браузере проверены 84 переключения цвета в каталоге, 90 сочетаний товара и цвета на страницах всех 34 товаров, фильтры, мобильный вид, переходы и ошибка загрузки изображения. В сборке 51 маршрут. Исправления изображений главной и 3D-калькулятора из предыдущего обновления сохранены.

Этот репозиторий содержит только готовую сборку. Исходный код хранится отдельно. GitHub Pages публикует ветку main из корня репозитория. Демо помечено noindex, nofollow.
